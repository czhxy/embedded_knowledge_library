# 嵌入式知识库

面向嵌入式软件学习与面试准备的个人知识库。**纯 Markdown + Obsidian**，图片随库自包含，可整体迁移到 Mac。

---

## 一、设计目标

| 你的需求 | 本库的做法 |
|---|---|
| 收录所学所有知识 | 按技术领域分层，9 大领域覆盖 编程 / 硬件 / MCU / RTOS / 协议 / OS / 工具 / 电机控制 / 面试 |
| 分类清晰、易增改 | 编号文件夹 + 每个领域一份索引（MOC），新增笔记放进对应子文件夹即可 |
| 图片不受本地影响 | 粘贴/拖入的图片自动存进 `99-附件/`，相对路径引用，换电脑不断图 |
| 碎片记录与定期汇总 | 统一 `00-Inbox/Inbox.md` 随手记，每周加工进正式笔记并归档 |

## 三、日常使用流程

### 1）随手记（学习时 / 工作后）

打开 `00-Inbox/Inbox.md`，在当天日期下追加一条：

```md
- [ ] #BLE 广播间隔与连接间隔的区别：……
```

不需要想放哪，用标签标注主题即可。

### 2）定期汇总（每周，或碎片积累够了）

1. 打开 Inbox，逐条处理 `- [ ]` 未完成项。
2. 把内容加工进对应领域的具体笔记。
3. 改为 `- [x]`，并把该段移到 `99-归档/Inbox归档/YYYY-MM.md`。
4. 提交一次 Git。

### 3）新建正式笔记

用 `模板/知识笔记模板.md` 新建笔记（Obsidian 命令面板：`Templates: Insert template`，需在核心插件中启用 Templates）。
图片直接粘贴或拖入即可，会自动存入 `99-附件/`。

## 四、图片与迁移

- **新内容**：图片存 `99-附件/`（按主题再分一层），引用相对于库内路径，整个文件夹复制即完整。
- **XMind**：全部导图已转换，图片从 `.xmind` 内嵌资源导出到 `99-附件/<主题>/`，共 148 张，链接已校验。
- **迁 Mac**：复制整个文件夹，或 `git clone`，无需重新贴图。

## 五、版本管理（Git）

本目录已初始化为 Git 仓库。首次提交：

```bash
git add .
git commit -m "初始化嵌入式知识库"
```

之后每次汇总或大改后提交。`.obsidian/workspace*.json` 已忽略（各机器 UI 状态不同，避免冲突）。

## 六、与 XMind 的关系

- 导图适合搭框架、面试前速览；Markdown 适合写详解、贴图、留碎片。
- **日常做法**：在 `xmind导图/` 下维护脑图，然后运行转换脚本生成 Obsidian 笔记：
  ```bash
  node "xmind导图/tools/batch_migrate.mjs"           # 只转换新增/修改的导图
  node "xmind导图/tools/batch_migrate.mjs" --force   # 全部重建
  ```
- 新增导图需先在 `xmind导图/tools/mapping.json` 补一条映射，详见 `xmind导图/CLAUDE.md`。
