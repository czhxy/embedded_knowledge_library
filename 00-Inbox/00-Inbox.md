# 00 · Inbox 使用说明

## 这是什么

所有「刚学到、还没想好放哪」的碎片，先扔进 [[Inbox|Inbox]]，**学习时不要纠结分类**。

## 记录格式

在当天日期标题下追加一行：

```md
- [ ] #主题标签 一句话知识点
    - 可选的展开：代码、图示、链接
```

## 汇总流程（每周，或碎片够多时）

1. 打开 [[Inbox|Inbox]]，逐条处理未勾选 `- [ ]` 的条目。
2. 把内容剪切/加工进对应领域的正式笔记（分类见 [[README|总览]]）。
3. 处理完后把 `- [ ]` 改成 `- [x]`。
4. 把已处理段落移到 `99-归档/Inbox归档/YYYY-MM.md`，Inbox 保持干净。
5. 提交一次 Git。

## 小技巧

- 标签用主题关键词（如 `#BLE` `#C语言` `#FreeRTOS`），方便用搜索或标签面板检索。
- 不确定归属的，先放最近的大类，汇总时再细调。
